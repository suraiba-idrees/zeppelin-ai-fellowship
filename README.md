# 📖 Overview

This repository follows a **monorepo architecture**, allowing multiple AI applications to be developed within a single codebase while maintaining independent project structures.

The projects explore practical applications of:

- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Prompt Engineering
- Semantic Search
- Vector Databases
- AI-powered Productivity Tools
- Full-Stack AI Development

Development follows collaborative software engineering practices using feature branches, pull requests, code reviews, and staged integration.

# 🚀 Projects

## 📄 AI Resume Screener & Feedback Engine

An AI-powered resume evaluation platform that analyzes resumes against job descriptions and generates structured ATS-style feedback using Google Gemini.

### Features

- Resume Upload (PDF/DOCX)
- Job Description Analysis
- ATS Resume Matching
- Skill Gap Identification
- Resume Improvement Suggestions
- Structured JSON Output
- AI-generated Feedback

**Tech Stack**

- Next.js
- FastAPI
- Google Gemini
- Python

**Project Status**

✅ Production Ready

---

## 📚 AI Study Companion

An AI-powered learning assistant that enables students to upload study materials, convert them into semantic vector representations, retrieve relevant knowledge using Retrieval-Augmented Generation (RAG), and generate personalized AI-assisted study plans.

### Features

- Document Upload
- PDF/Text Extraction
- Intelligent Document Chunking
- Embedding Generation
- Qdrant Vector Database
- Semantic Retrieval
- AI Study Plan Generation

**Tech Stack**

- Next.js
- FastAPI
- Google Gemini
- Qdrant
- Python

**Project Status**

🚧 Active Development

# 🌳 Development Workflow

The repository follows a Git feature-branch workflow.

```text
main
 │
 ▼
dev
 │
 ├────────────┬─────────────┬──────────────┬─────────────┐
 │            │             │              │
 ▼            ▼             ▼              ▼
Feature     Feature       Feature        Feature
Branch      Branch        Branch         Branch
```

Every feature is developed independently, reviewed through Pull Requests, merged into **dev**, and eventually released through **main**.
